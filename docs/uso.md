# Uso del Proyecto

## Funcionalidades para clientes

- Consultar catálogo de bicicletas
- Ver disponibilidad
- Realizar reservas
- Consultar reservas activas o pasadas

## Funcionalidades para empleados

### Empleado técnico
- Registrar supervisión tras recepcionar
- Registrar mantenimientos
- Consultar historial de mantenimientos

### Empleado de facturación
- Entregar y recepcionar bicicletas
- Consultar ingresos/gastos

### Administrador
- Gestionar bicicletas
- Modificar precios
- Gestionar usuarios internos
- Supervisar reservas
