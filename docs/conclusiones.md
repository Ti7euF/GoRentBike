# Conclusiones

## Dificultades encontradas

- Diseño responsive para distintos tamaños de pantalla
- Organización de estilos CSS
- Integración de múltiples roles en una misma plataforma
- Gestión del ciclo completo de una reserva (reserva → entrega → recepción → supervisión → finalización)

## Aprendizajes

- Uso de Grid y Flexbox
- Creación de un sistema de diseño propio con variables CSS y tema dark/light
- Mejora en la estructuración de proyectos web
- Familiarización con Laravel y su arquitectura MVC
- Exportación de datos a PDF con Dompdf.

## Posibles mejoras
- Implementar pasarela de pago para completar el proceso de reserva
- Añadir notificaciones por email al confirmar o cancelar reservas
- Incorporar un sistema de valoraciones y comentarios de los clientes
- Panel de estadísticas avanzadas con comparativas entre periodos
